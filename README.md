# Untitled Speedster Stealth Game
### *In development*

Imagine Payday 2, but you're the Reverse Flash and you can enter flashtime. 

Built on top of the movement and trail-effect systems from [Race Against the Clock](https://github.com/voidprophet/race-against-the-clock).


This is a longer term project currently in development, check back for updates as well as the greybox once its done.
